## 新增

### 桌面外壳
- **Codex 风格主窗口**——全高会话侧边栏完全取代 Web UI 自带侧边栏（`!important` 规则隐藏）：
  按工作区分组会话、工作区建/删/重命名、会话重命名/复制/归档、点击切换、折叠把手（`Ctrl+Shift+S`）。
  新建工作区直接调系统目录选择器，无需手输路径。
- **远程控制（局域网）**——可选令牌鉴权 Web 控制台：查看/新建会话、发送提示词、中断任务、
  切换模型、审批工具调用、回答问题，实时推送事件。
- **合并设置页**——外壳 / Harness / 插件 / 会话 / 用量 五页签（会话含全文搜索与导出 ZIP）。
- **主题真正联动 Web UI**——外壳主题经官方 `ui-theme` RPC 驱动内嵌 Web UI；伴生插件注册附加
  主题并双向桥接主题插件。
- **桌宠**——透明置顶鲸鱼娘：待机漂浮、悬停凑近、单击 Q 弹 + 台词气泡、双击开窗、拖拽记忆位置、
  举牌显示用量、任务完成跳跃/出错摇头；`npm run pet <png>` 换素材。
- **全局字体**——预设下拉（默认 HarmonyOS Sans SC）或保留自定义，外壳与 Web UI 同步。
- **Web UI 用量文字条**——伴生插件在输入框上方常驻用量行。

### 修复与打磨（含本轮收尾）
- 侧边栏「运行中」耗时实时走动，不再定格 `0s`。
- 托盘桌宠菜单实时同步：右键隐藏后标签立即更新，托盘一次点击即可显示/隐藏桌宠（不再需要点两次）。
- 默认字体改为 HarmonyOS Sans SC，旧配置自动迁移。
- Electron `window.prompt()` 静默失效改用自定义模态框。
- 修复启动时出现的空白无标题小框（`[hidden] { display:none !important }`）。
