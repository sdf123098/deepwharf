## What's new

### Desktop shell
- **Codex-style main window** — a full-height session sidebar that fully replaces the web UI's own
  sidebar (hidden via an `!important` rule): workspace-grouped sessions, create/rename/delete
  workspaces, rename/duplicate/archive conversations, click-to-switch, collapsed-rail expand
  handle (`Ctrl+Shift+S`). New workspaces are picked through the native folder dialog — no typing paths.
- **Remote control (LAN)** — opt-in, token-authenticated web console: view/create sessions, send
  prompts, interrupt runs, switch models, approve tool calls, answer questions, stream live events
  from any device on your network.
- **Merged settings** — one window with Shell / Harness / Plugins / Sessions / Usage tabs
  (sessions get full-text search + ZIP export).
- **Theme truly linked to the web UI** — shell themes drive the embedded Harness UI via the official
  `ui-theme` RPC; the bundled `deepwharf-companion` plugin registers extra palettes and bridges
  theme-plugin themes both ways.
- **Desktop pet** — a transparent, always-on-top whale-girl: idle floating, hover lean-in, click
  bounce + speech bubbles, double-click opens the window, drag (position remembered), holds a live
  usage sign, celebrates on task finish / shakes on error. Regenerate from any art with `npm run pet <png>`.
- **Global font** — preset dropdown (default HarmonyOS Sans SC) or keep a custom family; shell + web UI follow.
- **Web UI usage line** — the companion adds a live usage readout above the composer.

### Fixes & polish (incl. this release's final round)
- Sidebar "running" elapsed time now ticks live instead of freezing at `0s`.
- Tray pet menu stays in sync: right-click-hiding the pet updates the label instantly, and one tray
  click shows/hides the pet (no more double-click).
- Default font changed to HarmonyOS Sans SC with automatic migration of old configs.
- Electron `window.prompt()` silent no-op replaced by a custom modal.
- Startup stray-modal (empty untitled dialog) fixed via `[hidden] { display:none !important }`.

## Install

- `DeepWharf-Setup-0.5.0-x64.exe` — NSIS wizard (per-user by default, pick your directory, no admin needed).
- `DeepWharf-Portable-0.5.0-x64.exe` — portable, no install.
- Overwrites preserve your data (`%APPDATA%`).

## Notes

- Bundled Node runtime + vendored Harness; works offline. Install is fast (pruned payload, `compression: store`).
- Signed with a local test certificate chain (`O=DeepWharf Contributors`); external distribution still
  needs a CA cert (SmartScreen may warn). See `CODE_SIGNING.md`.
- Full history in `CHANGELOG.md`; engineering decisions archived in `docs/会话与实施记录.md`.
